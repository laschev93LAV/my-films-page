# My Film Page

- Учебный проект страницы с любимыми фильмами.
- Свёрстана с нуля на HTML и CSS

## Демо

[Открыть проект] https://laschev93lav.github.io/my-films-page/

## Стек

- HTML5 (семантическая верстка)
- CSS3 (Flexbox, CSS-переменные)
- Адаптивная верстка

## Что внутри

- 'index.html' - главная страница
- 'styles.css' - стили
- 'images/' - постеры фильмов

## Что реализовано

- Семантическая вестра ('<header>', '<main>', '<article>')
- Карточки фильмов на Flexbox
- Фиксированая шапка
- Кнопка 'наверх' с плавным скроллом
- Бейджи 'New' на карточках через (position: absoute;)
- Адаптиность под мобильные
